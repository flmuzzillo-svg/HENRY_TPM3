# Guía Integral de Preguntas y Respuestas: Área Técnica y Operaciones

Este documento consolida los protocolos, metodologías de desarrollo, mantenimiento de infraestructura y estándares de calidad técnica en un entorno corporativo.

---

## 1. Desarrollo de Software y Ciclo de Vida (SDLC)

**Pregunta 1: ¿Qué metodologías se aplican para garantizar la entrega continua?**
Respuesta: La organización utiliza marcos de trabajo ágiles, principalmente Scrum y Kanban, integrados con prácticas de DevOps. El ciclo comienza con el refinamiento de historias de usuario en el backlog, seguido de sprints de desarrollo de dos semanas. Se implementan pipelines de Integración Continua y Despliegue Continuo (CI/CD) para asegurar que el código sea probado y desplegado de forma automatizada en entornos de staging y producción.

**Pregunta 2: ¿Cómo se gestiona el control de versiones y la revisión de código?**
Respuesta: Se utiliza Git como sistema de control de versiones distribuido bajo un flujo de trabajo de 'Gitflow' o 'Trunk-based development'. Cada cambio requiere un Pull Request (PR) que debe ser revisado por al menos dos pares para garantizar la calidad del código, el cumplimiento de los estándares de estilo y la detección temprana de posibles vulnerabilidades de seguridad.

**Pregunta 3: ¿Cuál es el protocolo ante un incidente crítico en producción?**
Respuesta: Ante un incidente de severidad 1 (S1), se activa el Comité de Crisis Técnica. Se designa un Incident Commander (IC) que coordina la comunicación y las tareas de mitigación. El objetivo primordial es el restablecimiento del servicio (MTTR - Mean Time To Recovery). Una vez resuelto, se realiza un Post-Mortem obligatorio para identificar la causa raíz (Root Cause Analysis) y establecer acciones preventivas.
